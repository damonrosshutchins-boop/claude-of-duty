# Froydinger browser edition

Play: https://froydinger.github.io/claude-of-duty/

On iPhone or iPad, open the link in Safari, choose Share, then Add to Home Screen. Enable Open as Web App if offered. Launch the new icon and turn the phone sideways for more room. On Android, open the link in Chrome and choose Install app or Add to Home screen.

An internet connection is needed for the first load. The service worker caches successfully fetched game files as you play; unvisited maps, classes, or other uncached assets still need a connection. Browser storage may be cleared by the device.

Pushing to `main` publishes the runtime game through the Deploy browser game GitHub Actions workflow. The optional server-backed public play counter is disabled on this static edition.

Original game implementation: [Luckey Faraday / claude-of-duty](https://github.com/luckeyfaraday/claude-of-duty). Original MIT license, attribution, and third-party asset notices remain in this fork.
